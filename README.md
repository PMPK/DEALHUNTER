# Zanzibar Reality (prototype)

Travel reality-check map for Zanzibar. Static React + TypeScript app, no backend, no API keys.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit + UI tests
npm run validate   # typecheck + tests + production build
npm run preview    # serve ./dist
```
Docs: [PRODUCT](PRODUCT.md) · [ACCEPTANCE](ACCEPTANCE.md) · [DATA_MODEL](DATA_MODEL.md) · [STATE](STATE.md).
All scores are unverified seed estimates; hotels and offers are synthetic DEMO data.
